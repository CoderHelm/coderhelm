---
title: Triggers
description: Start a plugin run from a person's brief, on a schedule, or when a release is published.
---


Anyone who can use plugins can start a run from the plugin's page with **Write a brief**: "What should it write, for whom, and what must it mention?" They can also pick a **Repository (optional)**, for work that is about one repository's changes. `triggers` adds more ways to start a run.

## Manual brief form

```yaml
triggers:
  - on: manual
    form:
      brief: text
      channels: [linkedin, blog, email]
```

Each form field is `text` (a box to write in) or a list of choices to pick from, at most 10 fields. The run receives the answers and who asked. That person can never approve the run's output.

Any trigger can name the agent that answers with `agent:` (its file's name, without `.md`); without it, the first agent answers. Only a manual trigger has a `form`, and only a schedule has a `cron`.

## Schedule

```yaml
triggers:
  - on: schedule
    cron: "0 14 * * MON"
```

`cron` has five fields, in UTC: minute, hour, day of month, month, day of week. A scheduled run that finds nothing to do should say so and save nothing; write that into the agent's instructions. Turning a plugin off, or removing it, stops its schedules.

## Release

```yaml
triggers:
  - on: github.release
    agent: launch-writer
    repos: [your-org/web]      # optional: only these repositories
```

Runs when CoderHelm writes [release notes](/getting-started/reviewer#release-notes) for a new release tag on a repository the team connected, and the run gets those notes. `repos` limits it to some repositories (`owner/name`).

## Runs

Every run is listed in **Plugins**, under **Runs**, with what started it (manual, schedule or release), the plugin version, who asked, the tokens used and the drafts it saved. A run is queued, running, completed, failed, or refused (for example when a limit is reached), with the reason.

Adding a trigger in a new version waits for an admin. See [Versioning and updates](/plugins/versioning).
