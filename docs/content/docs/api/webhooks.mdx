CoderHelm sends an HTTP `POST` to your endpoints when it does something: a run starts, finishes, fails or waits for an answer, it opens a pull request, posts a review, fixes CI, takes an alert, finds a problem in your logs, publishes release notes, or someone approves a plan. Every request is signed the [Standard Webhooks](https://www.standardwebhooks.com/) way, retried for about a day when your endpoint can't take it, and recorded on the **Deliveries** page.

<Callout title="Looking for the webhooks CoderHelm receives?">
GitHub, Jira, AWS SNS and the other services that send events **to** CoderHelm are on [Incoming webhooks](/api/incoming-webhooks).
</Callout>

## Quick start

<Steps>
<Step>

### Add an endpoint

An admin opens **Settings**, then **Webhooks**, and chooses **Add endpoint**: an `https://` address, a description, and the events to send (or all of them). Or use the API with a key that has the `webhooks` scope:

```bash
curl -X POST https://api.coderhelm.com/api/webhooks/endpoints \
  -H "Authorization: Bearer $CODERHELM_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://hooks.example.com/coderhelm", "description": "Deploy bot", "events": ["run.completed", "run.failed"]}'
```

</Step>
<Step>

### Keep the signing secret

The answer, and the dashboard right after you add the endpoint, show its signing secret once: `whsec_` followed by 32 random bytes in base64. Store it with your endpoint's other secrets. Admins can reveal it again later, and rotate it.

</Step>
<Step>

### Verify, then answer quickly

Check the signature and the timestamp of every request ([below](#verifying-signatures)), skip events you already handled (by `webhook-id`), and answer with any `2xx` within 10 seconds. Do slow work after you answer, from a queue.

</Step>
<Step>

### Send a test event

Choose **Send test event** on the endpoint's page, or call `POST /api/webhooks/endpoints/{endpoint_id}/test`. A `webhook.test` event arrives, signed like every other, and the attempt shows on the page with your endpoint's answer.

</Step>
</Steps>

## What a request looks like

```http
POST /coderhelm HTTP/1.1
Host: hooks.example.com
Content-Type: application/json
User-Agent: CoderHelm-Webhooks/1.0 (+https://docs.coderhelm.com/api/webhooks/)
webhook-id: evt_01JBEVNT8M1N4P7Q0R3S6T9V2W
webhook-timestamp: 1792420307
webhook-signature: v1,K5oZfzN95Z9UVu1EsfQmfVNQhnkZ2pj9o9NDN/H/pI4=

{"id":"evt_01JBEVNT8M1N4P7Q0R3S6T9V2W","type":"run.failed","created_at":"2026-10-26T14:31:47.512Z","team_id":"TEAM#7c1f0e2a","api_version":"2026-10-26","data":{...}}
```

Every event has the same envelope:

| Field | What it is |
| --- | --- |
| `id` | The event's id: `evt_` and a ULID. The same on every retry, every endpoint and every resend, and sent as the `webhook-id` header. Use it as an idempotency key. |
| `type` | The event type, such as `run.completed`. |
| `created_at` | When it happened (RFC 3339). |
| `team_id` | Your CoderHelm team, as [`GET /api/me`](/api/reference/account/get-me) returns it. |
| `api_version` | The version of the event's shape, `2026-10-26` today. See [Versioning](#versioning). |
| `data` | The event's own fields, listed for each type below. |

The headers:

| Header | What it is |
| --- | --- |
| `webhook-id` | The event id. |
| `webhook-timestamp` | When this attempt was sent, in Unix seconds. A retry has a new timestamp and a new signature. |
| `webhook-signature` | `v1,` and a base64 signature. While a rotated secret still signs there are two, separated by a space. |

## Verifying signatures

The signature is the HMAC-SHA256 of `<webhook-id>.<webhook-timestamp>.<raw body>`, keyed with your secret's bytes (the part after `whsec_`, base64-decoded), in base64. To check a request:

1. Read the **raw** body, before any JSON parsing. Parsing and printing the JSON again changes the bytes and the signature fails.
2. Refuse a `webhook-timestamp` more than 5 minutes from your clock, so an old request can't be played again.
3. Work out the signature and compare it, in constant time, with each `v1,` entry of `webhook-signature`. Accept the request when any entry matches.

Any [Standard Webhooks library](https://github.com/standard-webhooks/standard-webhooks/tree/main/libraries) (JavaScript, Python, Go, Rust, Java, Ruby, PHP, C# and more) does all three; pass it your `whsec_` secret as it is. Or copy one of these:

<Tabs items={['Node.js', 'Python', 'Go', 'Rust']}>
<Tab value="Node.js">

```ts
import { createHmac, timingSafeEqual } from 'node:crypto';

const TOLERANCE_SECONDS = 5 * 60;

/** `rawBody` is the request body exactly as it arrived (a Buffer). */
export function verifyWebhook(
  rawBody: Buffer,
  headers: Record<string, string | undefined>,
  secret: string,
): boolean {
  const id = headers['webhook-id'];
  const timestamp = headers['webhook-timestamp'];
  const signatures = headers['webhook-signature'];
  if (!id || !timestamp || !signatures) return false;
  const ts = Number(timestamp);
  if (!Number.isInteger(ts) || Math.abs(Date.now() / 1000 - ts) > TOLERANCE_SECONDS) return false;
  const key = Buffer.from(secret.replace(/^whsec_/, ''), 'base64');
  const expected = Buffer.from(
    createHmac('sha256', key).update(`${id}.${timestamp}.`).update(rawBody).digest('base64'),
  );
  return signatures.split(' ').some((entry) => {
    const [version, signature] = entry.split(',');
    if (version !== 'v1' || !signature) return false;
    const got = Buffer.from(signature);
    return got.length === expected.length && timingSafeEqual(got, expected);
  });
}

//     return res.sendStatus(401);
```

<Tab value="Python">

```python
import base64, hashlib, hmac, time

TOLERANCE_SECONDS = 5 * 60

def verify_webhook(raw_body: bytes, headers, secret: str) -> bool:
    """raw_body is the request body exactly as it arrived."""
    msg_id = headers.get("webhook-id")
    timestamp = headers.get("webhook-timestamp")
    signatures = headers.get("webhook-signature")
    if not (msg_id and timestamp and signatures):
        return False
    try:
        ts = int(timestamp)
    except ValueError:
        return False
    if abs(time.time() - ts) > TOLERANCE_SECONDS:
        return False
    key = base64.b64decode(secret.removeprefix("whsec_"))
    signed = f"{msg_id}.{timestamp}.".encode() + raw_body
    expected = base64.b64encode(hmac.new(key, signed, hashlib.sha256).digest()).decode()
    for entry in signatures.split():
        version, _, signature = entry.partition(",")
        if version == "v1" and hmac.compare_digest(signature, expected):
            return True
    return False
```

```go
package webhooks

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/base64"
	"net/http"
	"strconv"
	"strings"
	"time"
)

const tolerance = 5 * time.Minute

// Verify checks a request. rawBody is the body exactly as it arrived.
func Verify(rawBody []byte, h http.Header, secret string) bool {
	id, ts, sigs := h.Get("webhook-id"), h.Get("webhook-timestamp"), h.Get("webhook-signature")
	if id == "" || ts == "" || sigs == "" {
		return false
	}
	sec, err := strconv.ParseInt(ts, 10, 64)
	if err != nil {
		return false
	}
	if d := time.Since(time.Unix(sec, 0)); d > tolerance || d < -tolerance {
		return false
	}
	key, err := base64.StdEncoding.DecodeString(strings.TrimPrefix(secret, "whsec_"))
	if err != nil {
		return false
	}
	mac := hmac.New(sha256.New, key)
	mac.Write([]byte(id + "." + ts + "."))
	mac.Write(rawBody)
	expected := []byte(base64.StdEncoding.EncodeToString(mac.Sum(nil)))
	for _, entry := range strings.Fields(sigs) {
		version, sig, ok := strings.Cut(entry, ",")
		if ok && version == "v1" && hmac.Equal([]byte(sig), expected) {
			return true
		}
	}
	return false
}
```

```rust
// Cargo.toml: base64 = "0.22", hmac = "0.12", sha2 = "0.10"
use base64::{engine::general_purpose::STANDARD, Engine};
use hmac::{Hmac, Mac};
use sha2::Sha256;

const TOLERANCE_SECS: i64 = 5 * 60;

/// `raw_body` is the body exactly as it arrived; `now` is Unix seconds.
pub fn verify_webhook(
    raw_body: &[u8],
    id: &str,
    timestamp: &str,
    signatures: &str,
    secret: &str,
    now: i64,
) -> bool {
    let Ok(ts) = timestamp.parse::<i64>() else { return false };
    if (now - ts).abs() > TOLERANCE_SECS {
        return false;
    }
    let Ok(key) = STANDARD.decode(secret.strip_prefix("whsec_").unwrap_or(secret)) else {
        return false;
    };
    signatures.split_whitespace().any(|entry| {
        let Some(sig) = entry.strip_prefix("v1,") else { return false };
        let Ok(sig) = STANDARD.decode(sig) else { return false };
        let mut mac = Hmac::<Sha256>::new_from_slice(&key).expect("HMAC takes any key length");
        mac.update(format!("{id}.{timestamp}.").as_bytes());
        mac.update(raw_body);
        mac.verify_slice(&sig).is_ok() // compares in constant time
    })
}
```

## Retries

An attempt counts as delivered when your endpoint answers any `2xx` within **10 seconds**. Redirects are not followed.

| Your endpoint's answer | What CoderHelm does |
| --- | --- |
| `2xx` | Delivered. |
| No answer in 10 seconds, a failed connection, `408`, `429` or any `5xx` | Tries again later. |
| Any other `4xx`, or a `3xx` | Stops: the answer won't change by itself. Fix it and press **Resend**. |

Retries wait 5 seconds, 1 minute, 5 minutes, 30 minutes, 1 hour, 3 hours, 6 hours, 6 hours and 8 hours: ten attempts in all, over about 24 and a half hours. Every attempt carries the same `webhook-id` and body, with a new timestamp and signature. Events can arrive out of order, so use `created_at` (and the fields in `data`) rather than arrival order.

### Endpoints that keep failing

When every delivery to an endpoint has failed for **5 days**, with no success in between, CoderHelm turns the endpoint off and emails your team's admins. Nothing is sent to it until an admin turns it back on in **Settings**, then **Webhooks** (or with `PUT /api/webhooks/endpoints/{endpoint_id}` and `"enabled": true`). Turning it back on starts the count again. Events from while it was off are not sent by themselves: replay them.

### Resend and replay

CoderHelm keeps each event for **14 days**, as long as its Deliveries record.

- **Resend** sends one delivery's event again, now, whether it was delivered or not: from the endpoint's page, the **Deliveries** page, or `POST /api/webhooks/endpoints/{endpoint_id}/deliveries/{delivery_id}/resend`.
- **Replay** sends every kept event of a time range again to one endpoint, oldest first, each as a new delivery with retries: `POST /api/webhooks/endpoints/{endpoint_id}/replay` with `since`, `until` and, to send only events that endpoint never got, `"only_failed": true`. At most 500 events per call.

Both send the event with its original `id`, so a receiver that skips ids it has seen handles each event once.

## Testing

- **Send test event** on the endpoint's page (or `POST /api/webhooks/endpoints/{endpoint_id}/test`) sends a `webhook.test` event at once and shows your endpoint's answer. Tests go to that endpoint only, even when it is off or doesn't subscribe to them, and are never retried.
- Every attempt is on the endpoint's page and on **Deliveries** (source `webhook`), with the request's headers (the signature removed), the body, your endpoint's status code and its answer.
- **On your own computer:** CoderHelm only sends to public `https://` addresses, so `localhost` can't receive events. Run a tunnel such as `cloudflared tunnel --url http://localhost:3000` or `ngrok http 3000`, add the `https://` address it prints as an endpoint, and send a test event. Delete the endpoint when you're done.

## Security

- **HTTPS only.** Endpoint addresses must start with `https://` and can't hold a username or password.
- **Public addresses only.** An address that points inside a private network, at the machine itself, at a link-local or carrier-grade NAT range, or at a cloud metadata service (such as `169.254.169.254`) is refused when you save it. The name is resolved and checked again before **every** attempt, and the connection goes to the address that was checked, so a name that later changes its answer can't reach a private network.
- **Verify every request,** signature and timestamp, and refuse anything that doesn't verify with `401`. Never trust a request because of its source address: CoderHelm's addresses change.
- **Skip repeats** by `webhook-id`. Retries, Resend and replay send an event again on purpose.
- **Keep the secret secret.** It is stored encrypted, shown in full only when created, revealed or rotated, and every reveal and rotation is in the team's audit log.
- **Rotate without a gap.** **Rotate secret** (or `POST /api/webhooks/endpoints/{endpoint_id}/secret/rotate`) makes a new secret. For the next 24 hours (choose 0 to 168 with `overlap_hours`), each request carries two signatures, one per secret, so your endpoint keeps verifying with the old one until you switch it to the new one.
- **The data is about your team's work.** Events carry titles, repository names, pull request links and short error texts, never code or credentials.

## Versioning

Each event says which shape it has in `api_version`, `2026-10-26` today. Within a version, CoderHelm only adds: new event types, and new fields in `data`. Ignore fields and types you don't know, and don't depend on the order of fields. Renaming or removing a field, or changing what one means, makes a new version, announced in the [changelog](/changelog) beforehand.

## Managing endpoints with the API

The endpoint routes are under [Reference](/api/reference/webhooks/list-webhook-endpoints), in **Webhooks**, and need a key with the `webhooks` scope (an admin's key). A team has at most 20 endpoints.

| Route | What it does |
| --- | --- |
| `GET /api/webhooks/event-types` | The event types, each with an example. |
| `GET`, `POST /api/webhooks/endpoints` | List the endpoints, add one (the answer has its secret). |
| `GET`, `PUT`, `DELETE /api/webhooks/endpoints/{endpoint_id}` | Read, change (address, description, events, on or off) or delete one. |
| `GET /api/webhooks/endpoints/{endpoint_id}/secret` | Reveal the signing secret. |
| `POST /api/webhooks/endpoints/{endpoint_id}/secret/rotate` | Make a new secret, with an overlap. |
| `POST /api/webhooks/endpoints/{endpoint_id}/test` | Send a `webhook.test` event now. |
| `GET /api/webhooks/endpoints/{endpoint_id}/deliveries` | The endpoint's deliveries and their attempts. |
| `POST /api/webhooks/endpoints/{endpoint_id}/deliveries/{delivery_id}/resend` | Send one delivery's event again. |
| `POST /api/webhooks/endpoints/{endpoint_id}/replay` | Send a time range's events again. |
