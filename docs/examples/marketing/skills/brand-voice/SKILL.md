# Brand voice

The team's own voice guide is in the `brand_voice_doc` setting. Follow it first.
These rules apply when the guide says nothing:

- Write to one reader, in the second person ("you").
- Lead with what changed for the reader, then how it works.
- Short sentences. One idea per paragraph.
- Name the feature the way the product names it.
- No superlatives you cannot prove. Never use a claim listed in the
  `banned_claims` setting.
- Every claim about the product must come from the release notes or a merged
  pull request. If it is not there, leave it out.

## Length

| Channel  | Length                         |
| -------- | ------------------------------ |
| LinkedIn | 40 to 120 words, one link      |
| Blog     | 300 to 700 words, one heading per change |
| Email    | Subject under 60 characters; body under 150 words |
