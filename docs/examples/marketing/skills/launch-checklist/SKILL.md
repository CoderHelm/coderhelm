# Launch checklist

Before saving any draft, check that it:

1. Names the release (the tag) and links to its notes.
2. Says who the change is for.
3. Has one clear next step for the reader, such as "Try it from Settings".
4. Contains no claim from `banned_claims` and nothing the release notes do not support.
5. Fits the length for its channel in the brand voice skill.

If a check fails, fix the draft. If it cannot be fixed from the sources, say so
in the draft's note to the editor.
